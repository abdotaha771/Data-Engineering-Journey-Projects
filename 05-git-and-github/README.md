# Module 5: Git & GitHub

This module covers the version-control and collaboration skills used to build, maintain, and present data engineering projects.

## Learning Resource

- **[Complete Git and GitHub Tutorial For Data Engineers (2025)](https://youtu.be/Kr8l7rQGwNs)**

## Why This Module Comes Before Cloud

Cloud projects create infrastructure, data, and credentials that must be managed safely and reproducibly. Git and GitHub provide the workflow for tracking those changes, collaborating on code, documenting decisions, and reviewing changes before they reach a shared environment.

## Topics

### Git fundamentals

- Repository setup and configuration
- Working trees, staging, commits, and history
- Branches, merges, rebases, and conflict resolution
- Remote repositories, tags, and release-oriented workflows

### GitHub collaboration

- Creating and maintaining repositories
- Pull requests and code review
- Issues, discussions, and project planning
- Writing useful README files and documenting projects

### Data engineering practices

- Creating a practical `.gitignore`
- Keeping passwords, API keys, service-account files, and local data out of version control
- Writing focused commits with meaningful messages
- Reviewing diffs before pushing or opening a pull request
- Using branches to isolate experiments and infrastructure changes

## Practice Checklist

- [ ] Create a repository and make an initial commit.
- [ ] Create a feature branch and merge it through a pull request.
- [ ] Resolve a merge conflict safely.
- [ ] Add an appropriate `.gitignore` and verify that secrets are not tracked.
- [ ] Document one project with setup, usage, and learning-source sections.
- [ ] Use `git log`, `git diff`, and `git status` to inspect work before sharing it.

## Outcome

By the end of this module, each later project should be reproducible, reviewable, and clearly documented on GitHub.
