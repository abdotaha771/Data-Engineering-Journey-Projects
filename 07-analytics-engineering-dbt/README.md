## 🛠️ Module 7: Analytics Engineering with dbt

Transforming raw warehouse data into analytics-ready models, implementing data testing and documentation, and establishing reliable data transformation workflows using dbt (data build tool).

### 📚 Learning Resources & Fundamentals:

- **Interactive DataCamp Skill Track:**
  - 📄 **[dbt Fundamentals](https://app.datacamp.com/learn/skill-tracks/dbt-fundamentals)**
- **Video Course:** [Data Build Tool (DBT) - The Ultimate Guide | With CI/CD](https://youtu.be/B8uwFmVt4sU)

The video complements the fundamentals track by connecting dbt concepts to a complete analytics-engineering workflow: source declaration, models, seeds, snapshots, tests, deployment, and CI/CD. It is especially useful for understanding how dbt projects are reviewed and promoted safely after the cloud warehouse foundation is in place.

### Learning Path

1. Define sources and build modular SQL models.
2. Add seeds, snapshots, macros, and reusable transformations.
3. Apply generic and custom data tests.
4. Generate documentation and expose lineage.
5. Introduce CI/CD checks before deploying changes.
